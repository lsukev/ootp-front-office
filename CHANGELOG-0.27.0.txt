OOTP Front Office 0.27.0 — everything since 0.26.0

New — The import shows you what it is doing. Pressing Refresh used to freeze the window for half a minute and then simply work, with no way to tell whether it was busy or broken. The cause was not the length of the import but its shape: seventy files and three hundred megabytes read in one unbroken run, so nothing else was answered for the duration — the page could ask for progress all it liked and the reply was stuck behind the very work it was asking about. It now hands control back every twenty thousand rows, and a bar reports the table, the file out of seventy, and the running row count, which climbs past three million on a real export. Each file is still written as one transaction, so a failure never leaves half a table behind. Reading the four largest files is a single step that cannot be broken up, so the bar holds for a few seconds on each — it says "Reading" while it does, which is the difference between a pause and a mystery.
